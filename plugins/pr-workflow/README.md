# pr-workflow プラグイン

Pull Requestを作成したあとの面倒を自動で見るプラグイン

## スキル

- **babysit-pr** — PR に張り付いて CI / レビュー / コンフリクトを監視・解消する（デフォルト）。観測のみ（「CI 通った？」「レビュー来てない？」「コンフリクトある？」等）にも対応する。

### 起動例

- `babysit-pr` / 「この PR 見張って」— merge まで監視し、問題を修正→push
- 「CI 通った？」— CI 結果だけ報告
- 「レビューついたら教えて」— 新着レビューを待って要約
- 「コンフリクトある？」— マージ可否とコンフリクトファイルを報告
